# Data

Nothing in this folder is committed to git.

- `synthetic/` is created automatically by `python run_pipeline.py --synthetic`.
- `home-credit/` is where the real Kaggle files go. Download them from
  https://www.kaggle.com/competitions/home-credit-default-risk/data and place
  `application_train.csv`, `installments_payments.csv` and `bureau.csv` here.
